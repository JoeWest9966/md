## 你的角度：一 · 增量价值

材料在当前目录里：

- `稿件/` —— 本批的稿件文件（纯正文，没有 front matter）
- `卡/` —— 本批的门槛卡 `*.card.md`（四栏 + `status`）
- `判据/adversarial-review.md` —— 判据、角度↔栏表、出口表、两把尺子：**按它执行**
- `判据/GLOSSARY.md` —— 术语真源（`_Avoid_` 规则、`档位`、Flagged ambiguities）
- `判据/adr/` —— 规程引到的 ADR（0001 术语与注解 / 0003 审读 / 0005 全程托管）
- `同轴已毕业.md` —— 同轴已发号条（本批之外）的索引

你判**成稿两栏**：`增量价值` 与 `何时别用`。

**你判的是「举证成不成立」，不是「这条到底有没有增量价值」**——那一栏没有真值持有者，真值延期到书级冷读与终读（ADR-0005 第三条）。所以：单边做法是不是真有的做法、差异点是不是读者可观察到的**行为**差别（不同的轨迹、可见状态、失败表现）、差异点有没有退化成形容词。**换皮**（差异点退化成形容词，即车轱辘话）是你的第一号猎物；形容词一律不通过。**砍**只有一条硬路径：差异点写不出可观察的行为差别。

顺带答一问，它是**判据**不是闲聊：**这条和同轴已定的哪条是同一件事？**（同轴已毕业条 = 同轴已发号段，含本批内其他条。）点得出同一件事即该条不过。只做索引级比较，不喂全文。
