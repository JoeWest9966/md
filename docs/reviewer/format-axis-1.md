## 输出格式（轴一 · 门槛卡复判）

一篇一份，逐栏一行：

```
### 《<中文标题>》总判：过 / 补 / 砍

| 栏 | 判词 | 判 |
| --- | --- | --- |
| <栏名> | <判词，必须引到正文的具体句子> | 过 / 不过 / 无法判定 |

同轴比对：<与同轴哪条是同一件事；点不出写「无可比条目」——同轴已毕业条为空池时才允许写这句；本批内其他条也算可比条目>
```

规矩：

- **引不出句子 = 无法判定**，按「差一关偏软」走补判，**不按砍走**。判「不过」同样要引原句。
- **先给杀它的理由**；给不出理由，才说通过。
- 补判轮只重审被改的栏与受影响的栏，不做全文复审；**判「补」的栏不许用「小改、仍弱」结案**——要么改到能过，要么走该栏出口。
- 你只读，不改任何文件。素材在 `稿件/` `卡/` `判据/` `同轴已毕业.md`；`判据/adversarial-review.md` 是判据与出口的真源，按它执行。
