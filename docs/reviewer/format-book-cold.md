## 输出格式（书级冷读报告）

```
水轴：<哪几轴通读下来是水；引原句>
该烧：<哪几条该烧号；每条引原句 + 与哪条重复 + 对哪个轴配额的影响；没有就写「无」>
配平：<哪轴太重 / 太轻；与阶梯是否相称>
阶梯：<L1 → L4 读下来爬没爬上去；断在哪>
断层：<部分之间的过渡断没断；跨轴重复>
```

规矩：

- 「该烧」里**烧了会破坏轴配额或阶梯**的，单独标一行 `留给终读裁：`——这一条不自动执行，它写进终读包。
- 引不出句子就写**无法判定**，不要为了填满五行而含糊。
- 你没有终审权：报告由驱动会话处理（烧号 / 返工 / 补轴），处理完才翻 `status: final`。
