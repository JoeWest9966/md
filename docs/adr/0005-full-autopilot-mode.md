# 全程托管模式

Status: accepted（决定于 [#12](https://github.com/JoeWest9966/md/issues/12)；人于 2026-10-16 宣布模式变更）。本 ADR 覆盖 [ADR-0003](0003-adversarial-review.md) 的「分裂档上呈人」与「审读员全权自裁（弃）」、[ADR-0002](0002-file-layout-and-numbering.md) 的「批大小由人的阅读预算定」。**被覆盖的旧结论一律保留原文 + 就地加注，不删痕**——本 ADR 引它们时按「节 + 原句」定位，不按行号（行号会烂）。

人宣布了四条，缺一不可：agent 自己选题、自己选**灵感**，不经他审；他不参与任何写作过程，只在最后读书；他不想看菜单（不逐条挑、不逐条批、不要「你选 A 还是 B」）；他要的就是「选套餐 → 等出书 → 读书」。

这是**模式变更**，不是选项——所以下面没有「要不要托管」，只有一件事：**原来靠人的那两道关，拿什么顶。**

## 一、人的两票：一票作废，另一票改写成书级的一票

地图 Notes 的分工行写的是「人只做两件事——定轴定调、判定『这算不算灵感』」。

- 第一件**已履行**：长期偏好锁死，别再问。
- 第二件**作废**：起草循环里不再有「这算不算灵感」的人的一票。顶上它的是**审读取严自裁**（第二条）+ 成书后的**终读**。
- 人的位置改写成**终读一票**：书成稿之后通读一遍，只说「烧哪几条」或「行」。它不是逐条判定，不是审读，也不在写作过程里——触发条件只有一个：书已经成稿。
- **终读包**（交给人的东西）= **全稿 + 一页遗弃名单**（编号 / 曾用标题 / 弃因，含「分裂取严」这个弃因）。遗弃名单是取严默认的唯一配重：他不看菜单，但看得见被退掉的菜，捞回来也是一句话。这是驱动者在本票范围内的一个设计取舍，不是人自己提的要求。

所以「人只做两件事」→「**人只做一件事：终读。**」

## 二、分裂档不再上呈：逐栏取严自裁

原条款（ADR-0003 决定「裁决」条）：「三家意见一致时审读员自裁明显档（过 / 砍 / 退回），分裂档上呈人」。

- **分裂档不再上呈**：全程托管下「上呈」没有收件人。
- **分裂 → 逐栏取严自裁**：该栏按「不过」结，落到该栏原本的出口——毕业审读（前三关）分裂 → **退回摘记池**（不占编号，可以再孵）；成稿审读（后两关）分裂 → **砍**（烧号进遗弃名单）。裁决是**逐栏**的，不是整篇投票：三个审读员本来就在看不同的东西，跨栏的「不一致」不是分裂。
- 理由：没有真值持有者时，唯一不撒谎的默认是「**不放进书里**」，这与「宁缺毋滥」同向。取宽等于把不能自证的「增量价值」交给三个不宽容读者里最宽容的那一个，而车轱辘话正是从那一栏漏进去的。
- 代价显式记账：被取严砍掉的真值不确定稿，在遗弃名单里只有编号、标题和「分裂」两个字，看不出冤枉——所以配重是终读包里的那页遗弃名单。**但判词纪律不因此放宽**：引不出句子仍是「**无法判定**」，仍走补判；补判不是分裂，分裂不是缺证据，两者出口不同。
- 由此改动出口表：「砍」不再是**唯一**一条硬砍路径，而是两条——① 差异点写不出可观察行为差别（判据性硬砍）；② 成稿审读逐栏分裂取严（本 ADR）。旧的「唯一硬砍路径」那句话作废。

## 三、「增量价值」这一栏的真值：延期，并常驻记账

ADR-0003 开头自己写着：门槛卡五栏里「增量价值」是唯一**不能自证**的一栏。它的真值持有者原本是人的那一票。人不在场了——这一栏**没有真值持有者**。处置是四件事，第一件是承认：

1. **降级为「判证」**：审读员在这一栏判的不再是「这条到底有没有增量价值」，而是「**举证本身成不成立**」——单边做法是不是文档里真有的做法、差异点是不是读者可观察到的**行为**差别、差异点有没有退化成形容词。能证的过，证不出的按不过。这是机器判得动的那一半，也正好是审读员一直在做的动作（ADR-0003 的第一号猎物就是「换皮」）。
2. **真值延期**：推到两处——(a) 成书后的**书级冷读**与**终读**（100 条里哪几条是水，在整本里比在单篇里显形得多）；(b) 书发出去之后的读者。第二处已经在本图**目的地**（一本书完成到可发）之外，所以本图内可交付的真值只有 (a)。
3. **代价常驻**：**全托管的真正代价就是它——「增量价值」在成书那一刻仍没有真值持有者，只有一个代用值（举证成立）。**门槛关得住「证不出增量的」，关不住「证得出、但读者仍觉得是换皮」的。这句话留在 ADR 里当账单：任何一次「反正审读过了」，先回答「哪一栏是代用值」。
4. **不接受「反正也差不多」**：这条代价对应下面两条机制（失灵探针 + 书级质量关）。缺任何一条，全托管就变成自己给自己发许可证。

## 四、车轱辘话的失灵探针（不依赖人）

书只有一种失败方式：变成车轱辘话。原设计靠人「读而不判、冒犯才开口」兜底。人不在，换四个能由机器数出来的信号：

| 信号 | 定义 | 阈值与动作 |
|---|---|---|
| **零砍批**（由软升硬） | 一整批一条没砍 | **连续 2 批** → 停批：开质检票，换审读人格重审最近一批，并查判词引用率。原为软信号（只记进合批记录）：它是不依赖人、又按批及时的唯一信号，软着记等于没有 |
| **轴内重复**（新增；把「顺带一句」升成判据） | 审读员必须点名「这条与同轴已毕业 / 已成稿的哪条是同一件事」；点得出即该栏不过 | 某轴因重复被砍 **≥3 条** → 该轴**停新增**，先做轴级去重（重复说明这一轴在自我引用，不是池子不够大） |
| **终读翻盘率**（旧的「翻盘率」改写） | 终读烧掉的条数 ÷ 进书条数 | **>10%** → **返工该轴**：只重审被烧条所在的那一轴（「不全文重审」那条禁令不变，见 ADR-0003「轮数是补判轮」） |
| **遗弃名单空转** | 一张选料票结束时 `book/graveyard.md` 零增长 | 连续 2 张选料票零砍 → 同「零砍批」处理：选料这一步也不许点赞 |

旧「翻盘率」（人开口推翻审读判定的比例）在新模式下**没有批级的数据来源**——人不在批里了。它改名成「终读翻盘率」并降为书级事后信号；它让出来的批级位置由**轴内重复**补上。

**信号的真实代价，写清楚：全程托管把质量信号从「批级及时」降成「书级事后」。**零砍批与轴内重复能按批、按轴及时发现「机制在空转」；但「这一条到底值不值得」的信号只在终读出现，也就是等整本读完。越早的批越可能带着系统性偏差一路写下去，纠偏要等到最后。这正是 `#9` 校准要**提前**把机制判一次假的原因。

阈值（连续 2 批 / ≥3 条 / >10%）是**首发校准值**，`#9` 之后按实测重定。

## 五、书级质量关：终读之前的两道，加终读那一票

现有全部门槛都是**逐条**判的。100 条全过，整本仍可能平庸——没有任何一处看「这一轴从头读下来是不是水」。补这一关，顺序钉死：

1. **书级冷读**（agent，fresh context，**没读过任何单篇**）：全稿从头读一遍，出书级冷读报告——哪几轴是水、哪几条该烧号、轴间配平（哪轴太重 / 太轻）、阶梯有没有真的从 L1 爬到 L4、部分之间的过渡断没断、跨轴重复。报「水」必须**引原句 + 点出与哪条重复 + 说明它对哪个轴配额的影响**（与审读同一套举证纪律：引不出 = 无法判定）。
2. **处理报告**：报告里「该烧」的条目在**给人读之前**处理完（烧号 / 返工 / 补轴）。唯一例外：烧了会破坏轴配额或阶梯——这种写进报告，留给终读一句话裁。
3. **终读**（人，一次）：读的是**报告处理完之后**的稿。他唯一的动作不该花在已知要改的字上。输出：「烧这几条 / 行」。终读之后不再有大改，只烧号、只修补被烧处伤到的承接（过渡、配额说明）。
4. **可发 = 终读说过「行」。**

状态流转钉死（ADR-0002 只写了 `draft → reviewed → final`，没交代谁翻最后一下）：

```
draft --(审读总判「过」，起草会话自动翻)--> reviewed
      --(书级冷读无异议，书级冷读那一会话翻)--> final
      --(人终读)--> 可发
```

翻 `reviewed → final` 的**不能是写这批的人**。这是「隔离」在书级上的同一条理由：审读员隔离是怕他替作者补台阶，这里怕的是自己给自己签字。

## 六、批大小与并发：换掉「人的阅读预算」这个口径

原条款（ADR-0002「并发」条）：批 3–5 条由人的阅读预算定，默认同时 2 批。

- **批大小 3–5 条不变，理由换掉**：现在定它的是**审读质量**——一批 = 3–5 篇正文 + 一份批级冷读报告，一个 fresh-context 审读员一次读得完、判词还引得出原句；再大，判词退化成形容词，审读就成了点赞。
- **并发口径换成「跨轴并行、轴内串行」**：**默认同时 2 批，硬顶 4 批，硬规则是不许两批同轴。**
  - 「不许同轴」不是配平偏好，是**结构约束**：号段由选料票发放，选料票一轴一张，同轴本来就排队；更要紧的是轴内重复检测要求每批看得见同轴已毕业的一切——两批同轴，两边都瞎。
  - **硬顶 4 = 阶梯四级**（L1 存续 / L2 运转 / L3 托付 / L4 放手）各一批：四个台阶各有一批在飞时，轴间配平判得动；超过 4 批，同一个台阶上挤两个轴，配平退回猜。
- **新上限防的是什么**（旧上限防的是「人一次读不完」）：① 同轴并行 → 轴内重复检测失灵；② 同一台阶上两批半成品互相拉扯 → 「哪一轴真厚」判不出来；③ 并发写作批的合并冲突。
- 串行合并的纪律不变；要并行就给每批一个 worktree。

## 七、人的一票留在哪：只剩封面与导出的最终形态

把图里「Not yet specified」那些形态问题按一条线切：**会不会被书以外的人看见、错了显不显眼。**

- **留给人**：**封面与导出的最终形态**（含 EPUB/PDF 成品长什么样）。这是唯一真会被外部世界看见的东西。
- **agent 自裁**：前言形态、部分之间的过渡、尾部「反灵感」是哪几条、结语与参考的形态、双语版本。
- **不在这条线里**：续作 / 系列——裁「做」的话那是**新一张地图**的事（本图目的地是一本可发的书），不毕业成本图的票。

为什么只留这一件：留多了，终读那一票就长成逐条审批，全程托管退回成模式变更之前的形态；一件不留，则是「错了很显眼」的地方也没有人意——那不是托管，是撒手。

## Considered Options

- **保留一个「三人分歧请人裁」的通道**（弃）：通道一开，判词就向它漂——审读员一旦知道分歧能甩给人，就不肯在分裂处下判断；而人收到的会是 99 条里最难的几十条，正好是他宣布不想看的菜单。
- **分裂档取宽**（弃）：理由见第二条。
- **另设一个「首席 agent」投「算不算灵感」**（弃）：多一层 agent 不等于多一份真值——它拿到的信息不比审读员多，只是把「取严」这条规则藏进了一个人格里，还多一处要对的账。
- **增量价值栏只判「单边做法是否真实存在」**（弃）：太松。真做法 + 形容词差异点会全过，而差异点退化成形容词正是车轱辘话的定义。
- **等书写完再由人逐条判**（弃）：那是 99 次菜单，人已明确不要。
- **书级质量关改成每批成稿时逐批判**（弃）：逐批看不到跨轴平庸与阶梯断裂——水是**整体**性质，只在全稿上显形。
- **终读提前（每次合批都让人读）**（弃）：等于恢复批级人读，与全程托管直接冲突。
- **批大小放宽到 8–10（人不再读，批可以更大）**（弃）：批大小现在的约束在审读员那边，不在人那边；放宽只会让判词退化。
- **并发不设上限**（弃）：轴内重复检测与轴间配平都会在同台阶并行时失灵。

## Consequences

- **新增流程词**，都进 [`GLOSSARY.md`](../../GLOSSARY.md) 标 `档位: C（流程词，不进正文）`：`全程托管` / `终读` / `书级冷读` / `零砍批` / `轴内重复`。
- **`#9`（两篇样章）是这套新机制的唯一校准点**（ADR-0003 早已定它为首次试跑；现在它是唯一——没有人的真值可以对表了）。零砍 = 校准失败那条判据不变，另加三条：取严档会不会把好稿砍掉（查判词引用率）、轴内重复检测在两条样章上说得出话吗、书级冷读的举证纪律落不落得了地。校准只能校「机制有没有在空转」，校不出「这条到底好不好」。
- **信号延迟是常态**，不是 bug：批级信号管机制空转，值不值得要等终读。
- **`notes/人类检查点与注意力.md` 的第 11 条（「由人的阅读速度定节奏」）成了自家反例**：它的一句话角度与反直觉点直接引「批大小由人的阅读预算定」，而本书自己在第六条把这条口径废了。不删它——它可能是这一轴里最硬的一条（「我们把自己这条做废了」比任何二手论证都结实），但它进书前必须重写反直觉点；那一轴的选料票要显式裁这件事。
