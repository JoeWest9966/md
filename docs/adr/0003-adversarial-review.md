# 对抗性审读机制

Status: accepted（决定于 [#7](https://github.com/JoeWest9966/md/issues/7)）。运行规程见 [`docs/adversarial-review.md`](../adversarial-review.md)。

**部分被覆盖（2026-10-16，全程托管）**：决定「裁决」条的「分裂档上呈人」与 Considered Options 的「审读员全权自裁（弃）」被 [ADR-0005](0005-full-autopilot-mode.md) 翻掉。**旧文一律保留 + 就地加注**，读的时候看到「（被覆盖）」就是它。

纯文稿没有「跑一下」这种检验，门槛卡（[#5](https://github.com/JoeWest9966/md/issues/5)）是它的替代品——但门槛卡是作者填的，而「增量价值」是五关里唯一**不能自证**的一栏。同时「这条值不值得进书」与「读者接不接得住」是两件事，一张卡装不下后者。所以：**隔离的只读审读员，扮演最不宽容的目标读者，两轴分开报。**

## 决定

- **审读员**：替换人格、无起草过程记忆、只读、fresh context；三个角度并行；人格是「目标读者里最不宽容的那一个」。
- **喂什么**：正文 + 门槛卡 + `GLOSSARY.md` + 同轴已毕业条的 leading word 与差异点索引。**不喂**起草会话记录、作者自述意图、其他审读员的报告。
  **（[#13](https://github.com/JoeWest9966/md/issues/13) 注）**「正文」指**稿件**文件本身；门槛卡不再是稿件 front matter 的一段，而是兄弟文件 `book/<nnn>-<slug>.card.md`——「喂两个文件」这条没变，变的是卡在哪里。
- **两轴**：门槛卡复判（作者侧）与冷读复述（读者侧），分开报、不互相抵消。
- **举证纪律**：每栏判词必须引到正文的具体句子；引不出只能写「无法判定」，而「无法判定」走补判、不走砍。
- **裁决**：三家意见一致时审读员自裁明显档（过 / 砍 / 退回），分裂档上呈人；人只在被冒犯时开口。审读**不**裁「这算不算灵感」——那始终是人的一票。
  - **（被覆盖）分裂档上呈人**：改为**逐栏取严自裁**——该栏按「不过」结，毕业审读分裂 → 退回**摘记池**，成稿审读分裂 → **砍**（烧号）。「上呈」在全程托管下没有收件人。代价与配重见 [ADR-0005](0005-full-autopilot-mode.md) 第二条。
  - **（被覆盖）「那始终是人的一票」**：起草循环里没有这一票了；顶上它的是逐栏取严，兜底的是成书后的**终读**。原句保留，它是本 ADR 当时的事实。
  - **（被覆盖）「人只在被冒犯时开口」**：批级人读整条作废——他不读批、不读单篇。人的开口位置移到成书后（**终读**）。

## Considered Options

- **作者自审**（弃）：增量价值不能自证；作者已同时持有两边，天然失去「反直觉」的参照。
- **单一审读员复审三遍**（弃）：三个角度糊在一个人格里，等于一个模糊的批评；matt `parallel-review` 的取法是「三个强的胜过一堆糊的」。
- **审读员共享起草上下文**（弃）：知道作者想说什么就会自动补台阶，「换皮」恰恰要靠不懂意图才挑得出来。
- **另立一张「审读卡」**（弃）：#5 已定审读就是门槛卡复判；再立一张＝两套标准。
- **council-mode 顾问辩论**（暂缓）：本机没装任何 `council-*` profile，走它等于退化模式；两轴审读的收益已够。
- **审读员全权自裁**（弃）：与地图 Notes 里「人判算不算灵感」的保留权冲突。**（此弃案已被 [ADR-0005](0005-full-autopilot-mode.md) 翻回：全程托管下保留权不存在了，改为全权自裁 + 取严默认。）**
- **所有不过都上呈人**（弃）：100 篇 × 5 关 = 500 次人的判定，预算爆，#5 已否。
- **把「术语没 ground」做成第六道门槛**（弃）：#5 已否第六关；它住审读的第二条轴。

## Consequences

- **冷读轴不进门槛**：grounding 是读者侧的事，不改「门槛」的五关定义。
- **审读的单位是批**（ADR-0002 的批），不是篇；一次审读覆盖 3–5 篇 + 一份批级冷读报告。
- **（被覆盖）人的预算守住了**：原为「他读整批，只在被冒犯时判；`reviewed → final` 在合批那一下翻」。全程托管下人的批级预算归零——他不读批、不读单篇，只在成书后投**终读**一票；`reviewed → final` 由**书级冷读那一会话**在书级冷读无异议时翻，起草会话不给自己签字（ADR-0005 第五条）。
- **机制自己会被质检**：四个信号落进**批级记录**（见 ADR-0002「地图与票」）——**零砍批**（升硬：连续 2 批 → 停批质检；**#9 校准后改判成「零发现批」**，见 [ADR-0005](0005-full-autopilot-mode.md) 第四条加注）、**轴内重复**（某轴因重复被砍 ≥3 条 → 该轴停新增，先做轴级去重）、**终读翻盘率**（>10% → 返工被烧条所在的轴）、**遗弃名单空转**（连续 2 张选料票零砍）。阈值是首发校准值，见 ADR-0005 第四条。
- **`#9` 两篇样章是这套机制的唯一校准点**（原为「第一次试跑」；现在没有人的真值可以对表，所以是唯一）。**（校准已于 2026-10-16 完成：两轮 + 两个探针，全文 [`proto/calibration-01.md`](../../proto/calibration-01.md)；信号 `零砍批` 按实测改判成 `零发现批`，见 [ADR-0005](0005-full-autopilot-mode.md) 第四条的加注。）**
- 新增流程词 `审读` / `审读员` / `冷读`，进 `GLOSSARY.md` 标 `档位: C（流程词，不进正文）`，不派生进书尾术语表；全程托管另增 `全程托管` / `终读` / `书级冷读` / `零砍批` / `轴内重复`。
