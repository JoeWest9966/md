# 对抗性审读

纯文稿没有「跑一下」这种检验。**门槛卡**就是「跑一下」的替代品（见 [#5](https://github.com/JoeWest9966/md/issues/5)），**审读**的活是把它判假。

分工一句话：**门槛是判据，审读是拿判据去判假的动作；审读只证伪。**「这算不算**灵感**」在全程托管下没有人的一票（[ADR-0005](adr/0005-full-autopilot-mode.md)）：起草环节由逐栏**取严自裁**顶住，成书后由人的**终读**兜底。

## 单位与时机

- 单位是**批**（ADR-0002 的批：一张写作票 + 一个会话 + 一个分支，3–5 篇），不是篇。一批写完、审完、合完，再开下一批。
- 两次审读，对齐 #5 的分关判定：
  - **毕业审读**（起草前）：`两边在场` / `leading word` / `反直觉` 三栏。逐条毕业时就审——错判的代价是一条废稿。
  - **成稿审读**（成稿后）：`增量价值` / `何时别用` 两栏，加冷读轴。
- 触发：起草完成即自动起审读（AFK），全程无人。人的位置只有一处，在书成稿之后：**终读**（见「裁决权与 status 流转」与「书级冷读」）。

## 审读员：人格与隔离

三个 fresh-context、只读、替换 system prompt 的审读员**并行**，各持一个角度。pi-subagents 的 `reviewer` profile 就是这个形状（`systemPromptMode: replace`、`inheritSkills: false`、tools 只有 `read/grep/find/ls`）。

替换人格正文：

```
你是《哲学与运行时》的目标读者里最不宽容的那一个：你已经在用 coding agent，见过太多把
已知东西换皮成「洞见」的文章，随时准备把这一篇关掉。你的活是把它判假，不是把它夸好。
先给杀它的理由；给不出理由，才说通过。
```

- **喂**：正文 + 门槛卡 + `GLOSSARY.md`（grounding 两种：前提 / 就地引入，判据见 [ADR-0001](adr/0001-terminology-and-annotation.md) 与「角度二的两把尺子」）+ 同轴已毕业条的 leading word 与三行差异点**索引**（不是全文）。
- **不喂**：起草会话记录、作者自述意图、其他审读员的报告。审读员之间互不可见，父会话合议。
- 理由：知道作者想说什么就会自动给他补台阶；「换皮」只有不懂意图才挑得出来。
- **引不出句子＝无法判定**：每栏判词必须引到正文的具体句子。引不出只能写「无法判定」，而「无法判定」按「差一关偏软」走补判，**不按砍走**——引不出句子是审读员没证据，不是稿子有罪。

## 三个角度

1. **增量价值**：对着卡片上「单边做法 / 组合做法 / 差异点」三行，问差异点是不是**读者可观察到的行为差别**（不同的轨迹、可见状态、失败表现）；形容词一律不通过。**换皮**（差异点退化成形容词，即车轱辘话）是本角度的第一号猎物。全程托管下这一栏判的是**举证成不成立**，不是「到底有没有增量价值」——那一栏没有真值持有者，见 ADR-0005 第三条。
2. **骨架与 ground**：骨架七槽齐不齐（其中**行为示意槽**单独判，尺子见下）；正文有没有**没 ground** 的术语或概念；两边是否都在场且各自不可替代（缺一边稿子就塌）。
3. **冷读复述**：见下。

顺带一句（每个审读员都答）：**这条和同轴已定的哪条是同一件事？** —— 只做索引级比较，不喂全文。全程托管下这一问已升为**判据**（不再是顺带）：点得出同一件事即该条不过，这条信号叫**轴内重复**，见 ADR-0005 第四条。**同轴还没有已毕业条时跳过这一栏**，别写「无可比条目」凑数（#9 校准：两轮八个审读员在空池子上恒空转）。

### 角度二的两把尺子（#9 校准补的）

这两条不是新门槛，是把「骨架与 ground」从形容词变成判据——校准实测它是这套机制里唯一没有成文尺子的一栏：同一份稿件，两份报告的「无 ground」清单能差出一条。

**行为示意槽**（骨架第七槽；两轮独立审读都在这槽上判不过）：

1. 它必须给出**一条正文别处没有的轨迹或状态差别**——时间轴上的位移、同一时刻两个做法的可见状态差、失败时各自的样子。把组合机制换一个排版重排一遍＝**填字游戏**，该栏不过。
2. 它必须与**场景、与它自己列出的状态、与组合机制里的闸**自洽。不自洽＝该栏不过，走补；槽位空着也是不过——**「删掉它」不是出口**。

**ground**：一句「它是哪一层的东西」或一句边界就算 ground。**免注**：通用技术词（agent、prompt、token、context）与字面名（枚举值、方法名、`pi.*` kind）。**用 `GLOSSARY.md` 标为 `_Avoid_` 的词去解释另一个词，不算 ground**——换皮换到注解层也还是换皮。

## 两轴，分开报，不互相抵消

- **轴一 门槛卡复判**（作者侧：这条值不值得进书）
- **轴二 冷读**（读者侧：读者接不接得住）

两轴分开报。一轴过、另一轴挂是常态（matt `code-review` 的两轴就是这个理由）；合并会掩盖。**冷读不是第六道门槛**（#5 已否掉第六关）。

### 轴一 · 门槛卡复判格式

一篇一份，逐栏一行：`栏名 | 判词（引原句） | 过 / 不过 / 无法判定`，末尾一行**总判：过 / 补 / 砍**。毕业审读只填前三栏，成稿审读只填后两栏。

### 轴二 · 冷读报告格式（≤300 字）

```
复述：<leading word 复述得出来吗；复述成了什么样>
边界：<说得出何时别用吗；说不出就写「说不出」>
裸术语：<哪句术语或概念没有 ground，引原句>
```

冷读由**另一个**无上下文、只读正文的 agent 做，它不看门槛卡、不看审读员报告。**「只喂正文」要真做到**：门槛卡挂在同一个文件的 front matter 里，所以给冷读的稿子必须先剥掉 `---` 那一段（#9 校准：不剥时，冷读报告会直接引用门槛卡）。

冷读是**一次抽样，不是一次检验**——同一份文本，两个冷读员抓到的裸术语可以一条都不重合（#9 校准实测）。所以它不单独定生死：它报的裸术语与两轴发现**合并去重**之后一起走进出口表。

## 出口表

| 总判 | 触发条件 | 处置 |
| --- | --- | --- |
| **过** | 五栏全过 | 起草 agent 翻 `status: reviewed` |
| **补** | 差一关偏软 / 无法判定 | 作者补举证或重写该栏；补判至多三次，第三次仍不过按「砍」或「退回」处理 |
| **砍** | ① 差异点写不出可观察行为差别（判据性硬砍）；② 成稿审读逐栏分裂取严（ADR-0005） | 烧号进 `book/graveyard.md`，文件删掉，git 留史 |
| **退回** | 毕业审读三栏不过 | 退回 `notes/<axis>.md` 摘记池，不占编号 |
| **取严** | 审读员逐栏意见分裂 | 不再上呈：该栏按不过结——毕业审读取严 → 退回摘记池；成稿审读取严 → 砍（烧号）。**判词引不出句子是「无法判定」，仍走补判，不是分裂** |

轮数是**补判轮，不是重审轮**：重写后只重审被改的栏与受影响的栏，不做全文复审——全文重审会把「改到过」变成磨洋工。**判「补」的栏不许用「小改、仍弱」结案**：要么改到能过，要么走该栏的出口（退回 / 砍）。#9 校准里唯一一次这么结案的栏，第二轮独立审读原样判不过，还顺带挖出一处新的自相矛盾。

## 书级冷读（成书后，全程托管）

单位是**整本**，不是批。一个 fresh context、**没读过任何单篇**的 agent 从头读完成书稿，出报告：

```
水轴：<哪几轴通读下来是水；引原句>
该烧：<哪几条该烧号；每条引原句 + 与哪条重复 + 对哪个轴配额的影响>
配平：<哪轴太重 / 太轻；与阶梯是否相称>
阶梯：<L1 → L4 读下来爬没爬上去；断在哪>
断层：<部分之间的过渡断没断；跨轴重复>
```

判「水」的举证纪律与审读相同：引不出句子只能写「无法判定」。报告里「该烧」的条目在**给人终读之前**处理完；唯一例外是烧了会破坏轴配额或阶梯的，留给终读一句话裁。它是硬关：不处理完，「可发」这个词不成立（ADR-0005 第五条）。

## 裁决权与 status 流转

```
draft --(审读总判「过」，起草会话自动翻)--> reviewed
      --(书级冷读无异议，书级冷读那一会话翻)--> final
      --(人终读)--> 可发
```

- **明显档审读员自裁，分裂档逐栏取严自裁**（#5 已定；「上呈人」被 ADR-0005 覆盖）。审读员是只读的，翻不了 status；`draft → reviewed` 由起草会话按总判翻，`reviewed → final` **不能**由起草会话翻——那是自己给自己签字。
- **终读**：书成稿、书级冷读报告处理完之后，人通读一遍，只说「烧这几条 / 行」。他不逐条填判定、不读卡、不参与写作；这是客人的退菜权，不是写作过程的一步。终读包 = **全稿 + 一页遗弃名单**（含「分裂取严」这个弃因）。
- **终读之后不再有大改**：只烧号（进 `book/graveyard.md`）与修补被烧伤的承接处（过渡、配额说明）。**可发 = 终读说过「行」。**
- **终读只能烧，不能捞**：被审读砍掉的稿已经不在书里，人也看不到——所以这套机制要防的是**漏砍**（零发现批 / 轴内重复），不是误砍；误砍的配重是遗弃名单那一页。

## 这套机制自己的质检

| 信号 | 含义 |
| --- | --- |
| **零发现批**（旧名「零砍批」；**硬信号**） | 一整批**没有任何一栏被判不过或无法判定，且冷读三行都给不出问题** → 连续 2 批 → 审读员在点赞：停批，换人格重审最近一批，并查判词引用率 |
| **轴内重复**（审读员点得出「与同轴哪条是同一件事」） | 某轴因重复被砍 ≥3 条 → 该轴停新增，先做轴级去重 |
| **终读翻盘率**（终读烧掉的条数 ÷ 进书条数） | >10% → 返工被烧条所在的那一轴（不全文重审）；原「人开口推翻审读判定的比例」在全程托管下没有批级数据来源 |
| **遗弃名单空转**（一张选料票结束时零增长） | 连续 2 张选料票零砍 → 同「零发现批」处理 |

四个信号落进**批级记录**——写作批那张票的结论评论里：审读总判 + 四个信号的读数（不另开文件，见 ADR-0002「地图与票」）。阈值是**首发校准值**（ADR-0005 第四条）。

**为什么把「零砍批」改判成「零发现批」**：出口表里「砍」只有一条窄路径（差异点退化成形容词），可修的缺陷一律走「补」，所以**健康批照样零砍**——#9 校准两轮零砍，同时挑出几十处真发现。数「砍」会把好批报成点赞，改成数「发现」。

**#9 校准已完成**（两轮共 8 个隔离审读员跑：第一轮三角度，第二轮三角度 + 两个「已知病灶」探针，全文在 [`proto/calibration-01.md`](../proto/calibration-01.md)）。读数：机制**不空转**——挑得出、可复现、还能挑出上一轮漏掉的；同时它判假了四条判据：

1. **`零砍批` 判据坏** → 改判「零发现批」（见上表与下面那段）。
2. **「骨架与 ground」没有成文尺子** → 补了「角度二的两把尺子」。
3. **冷读的隔离是假的** → 剥 front matter；并明说它是一次抽样。
4. **「小改、仍弱」的补判结不了案** → 纪律加一句。

**账单余额三项**（这两篇样章考不到，留给后面的批）：**砍路径**（差异点退化成形容词那一路，两轮都没触发）、**轴内重复**（要同轴有已毕业条才有输入）、**书级冷读**（要有一整本）。引用「机制已校准」时，先把这三项说清楚——它们不是「已知为空」，是「没被考过」。
