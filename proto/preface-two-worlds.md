# 两个世界的地图

有一个说法你可能已经听腻了：coding agent 的天花板不在模型，在使用它的人。这句话是对的，但没什么用——它没说天花板是哪一块，也没说谁来拆。这本书给一个具体的答案：**天花板在两个世界重叠的那一处。**

一个世界是**方法论**（matt skills：一套公开的 coding agent 工作方法，每个 skill 是一段命名的方法）。它住在你的脑子里和提示词里：把大活儿切成能单独验收的小片、动手之前先把问题问穿、先写一条会变红的判据（红＝测试挂）、做完把这次的失败变成下一次的检查。它管的不是模型怎么答，是你**怎么问、怎么验、怎么收**。

另一个世界是**运行时**（durable：pi 这套 coding agent 工具里的耐用运行时包，pi 就是跑 agent 的那层壳）。它住在你的进程下面：有一个地方存着这次工作的全部事实，有一次写入决定什么算发生过，有一个状态机保证崩掉之后还认得出自己走到了哪。它决定的是：你那套纪律能不能活过这一次打开的存储。

两个世界各自都有几千页的说明，但几乎没有人在同一个句子里谈过它们——写文档的人不需要：一边要教全部的纪律，一边要教全部的原语。这本书只教一件事：**两边接上之后，你能拿到任何一边都给不出的做法。** 所以它要一张图，且只要一张：不解释每一个地名，只让读者看清两个世界各自长什么样、各自管到哪、真正重叠的地方在哪。

## 第一个世界：运行时

**一、一个打开的存储，就是一台机器。** durable 对外的第一层叫 *Harness*（只负责打开存储、让 agent 跑在上面）。它打开的那个东西叫**会话（*Session*）**：会话里只有一条写入线（mutation line），所有写入排队从它过去——运行时唯一真正的保证就来自这条线。它也**不重试**：存储一出错，会话把自己整个关掉，想继续就重开一个。所以在这里，「还活着」不是进程的状态，而是**一个存储可以被重新打开**。

**二、只有一种事实。** 既然什么都要从存储里重算，存储里就得有一种不会再变的东西：*Entry*（唯一的事实：改不了，也删不掉）。它追加进去，永不原地改，全局有序，绝不复用。所有「模型此刻看得见什么」都是从它**算出来**的，不另存副本。你可以把指针挪开、让某条旧事实暂时看不见，但它还在那里。**「忘掉」和「不存在」是两件事**——这是全书的第一块地基，往下几乎每一篇都踩着它。

**三、没有半可见的状态。** *Commit*（一次原子写：要么全成，要么全不成）能把好几样写入打包成一次。运行时里没有「先发出去、回头再补落盘」的路径，所以一条进度可见的时候，它已经在存储里了——**没有半可见的状态**。代价同样干脆：commit 必须是短的——在里面等模型、等网络、等人，就是把整条写入线攥在自己手里。

这里还藏着一条容易被忽略的缝：**外部效果（发邮件、调外面的服务）永远不在任何一次 commit 里。** 它只能夹在「写下意图 → 出去做 → 写回结果」三段之间。于是崩溃重开时，你保证得了意图还在，保证不了效果没发生——**效果有没有发生，是你的事，不是运行时的事。**

**四、写入线不等于工作范围。** *Conversation*（一段工作自己的范围：收件箱、用量、它自己那套设置）才是「这件事」的单位。会话和 *Conversation* 是两个词，不能换着用——前者是那条唯一的写入线，后者是被隔离开的一段工作。平时它们总是一起出现，所以最容易混；等到你要并行、要分叉、要把一段活交出去，混用就要付代价。

**五、唯一有重量的一项。** 任务（*Task*）是一个每一步都得留下进展的状态机。它的形状是一句重复三次的话：**写下要做什么，出去做，回来写下做成了什么**。每个阶段结束至少留一次进展，重开时从最后一个没跑完的地方续。一个阶段跑完了却没留下任何东西，运行时不会认为它成功——它会判它 *faulted*（失败态）。**「我跑完了」不算数，「我留下了」才算数。** 这就是 durable 这个词真正的意思：不是不会崩，是崩了以后你还说得出自己走到哪。

**六、状态有地方放，也有寿命。** 文档（*Document*）是跟 *Entry* 在同一次写入里原子地改的一小块类型化 JSON 状态。寿命挂在归属上：挂在会话下的活过重开，挂在任务下的在任务结束时原子地退休。它存在的理由是：不是每样东西都该塞进上下文——应用自己的状态有它自己的家。

**七、这台机器是拼出来的。** 扩展（*Extension*）是一个命名束：一批工具、几段提示词、几个 hook（挂在动作前后自动跑）、几个任务，装在一起给这段工作用。*Registry*（只活在进程里：当前装了什么，运行中可变）记的是它们的名字。分界线在这：**代码在你的进程里，名字在存储里。**

**八、人看到的是一屏状态，不是一条流水。** *view* 是这段工作此刻的只读状态，*watch* 订阅它的变更。两条性质让它在本书里反复出场：第一，当前视图不是进度流的近似，**它就是全部事实**——因为可见的进度都已 commit；第二，watch 对迟到的客户端**不补播**：从当前视图开始，什么都不重放。所以「人晚到九十分钟」不是故障，是正常。没有这套东西，人的界面只能是一条日志；有了它，才可以短到一屏。

就说八个。剩下的名字——*Submission*、*Turn*、*Run*、工具、代码模式、环境、图片——各章用到的第一次会给一句注解，不在这里铺开。它们的细则属于 durable 自己的文档，这本书不复述。

## 第二个世界：方法论

matt skills 那边有三十八个 skill。但数量是**受控**的：一份新提案如果「用已有的 skill 就能组合出来」，它不会得到一个新 skill。所以真正传下去的不是三十八个动作，是四条信念。

**信念一：反馈速率是速度上限。** 「Always take small, deliberate steps. The rate of feedback is your speed limit.」这条信念的技术要求是**判据先于动作**：先有一条会红过的命令，再列假设；先想清楚改动从哪一处进去，再写测试。它的世界观是——不确定不是靠想得更清楚消除的，是靠把每一步变成一个能判真假的动作消除的。

**信念二：共同的词是回报最高的一步。** 一个精确的词换来命名一致、代码可导航、agent 少烧 token——而且这三样在之后每个会话里复利。所以「用词」是要主动施工的对象：词漂了当场叫停，模糊词给一个规范词，落地就写进文件。代价很笨：每次用词漂的时候你得停下来，而不是让它过去。

**信念三：组合优先于堆积。** 这套 skills 明确拒绝拥有你的流程——不做大框架，只发小纪律，理由是「如果它由已有 skill 组合而成，它就不该成为新的 skill」。动作数量受控，可变的是组合方式；八轴（本书的八个工程问题，全书目录就是这八节）乘三十八个动作的组合空间，就是这本书住的地方。

**信念四：人的注意力是稀缺资源，不是要被最小化的成本。** 原话很硬：「The human is the index. Not a cost to minimise: it is the price of human agency; spend it where human judgement matters.」落成动作，所有涉及人的设计都在做同一件事：**把人被问到的时机尽量往后推，只问一次，材料齐备。** 这是 push right（把人被问到的时机再往后推），是「一趟问完手头所有待决的事」，是「能交给 agent 查的事实不拿去问人」。

## 两个世界在哪重叠

现在把两张纸叠起来。

四条信念在**只用一边**的世界里都是**纪律**——纪律的意思是靠人记住、靠人执行、破了没人知道。而运行时那边有另一样东西：**结构**。结构不靠谁记住，因为不照做的路径根本不存在。

这本书的一百篇，每篇取一条方法论的动作，配一到两条运行时的原语，然后给你看一条轨迹：同一件事，按**单边做法**（只用一边就能做到的做法）走会走到哪，按组合做法走会走到哪。差别必须可观察——一屏状态、一次时间轴上的位移，或一种只有组合才会有的失败方式。

举个最短的例。信念四说「把人被问到的时机尽量往后推」。只用一边的世界里，这是一句纪律，破的方式是人回来发现界面丢了半小时；而运行时里，「人晚到」有一份保证在等着它——可见的进度全都已 commit，订阅又不补播，于是迟到的人看到的当前视图就是全部事实。push right 因此从一条靠自律的纪律，变成一条**可以推得很远的保证**。

反过来也要说清楚：**不补播**在运行时那边只是一条实现细节，单独存在时不产生任何方法论价值。两边都不在场的想法，在这本书里不进书——这是选料时最硬的一条。

## 读完这一篇，你手里有什么

**手里有：** 运行时的形状——只有一种事实、可见性等于已 commit、任务是有重量的状态机、扩展的名字活在存储里、人看到的是一屏状态而不是一条流水；方法论的四个信念；以及「这两个世界在哪儿重叠」这个问题本身。

**手里没有：** 任何一个原语的完整细则（那是 durable 文档的活）；任何一条具体的组合做法（那是正文的活）；任何运行时的调优参数（那些名字归各章，出现时就地一句注解）。

**读法：** 一百篇不分先后，但排成一条坡——从「机器活得过自己这次进程」，到「能同时干几件事、说得出干成没有」，到「不用每次重新解释世界」，到「翻车变成日常、人从订阅者变成事件」。每篇四百到九百字，一篇一个做法，并且说得出它什么时候不该用。

书名里有「哲学」和「运行时」两个词，但这本书不教任何一边。它只把两个世界放在同一张纸上，然后指着它们真正重叠的那一处——那台愿意替你记住一切的机器，和那套只肯一步一步走的纪律——说：看，这里可以盖东西。
