# 审读校准记录 01 —— #9 的两篇样章（唯一的校准点）

样章本身与第一轮审读在 [`review-01.md`](review-01.md)。本记录填的是**校准判据**，不是样章的成绩单。

[ADR-0003](../docs/adr/0003-adversarial-review.md) 把本票定为审读机制的第一次试跑；[ADR-0005](../docs/adr/0005-full-autopilot-mode.md) 之后它是**唯一**的校准点——人不再读稿，没有真值可以对表。所以这里判的不是「两篇写得好不好」，是**机制有没有在空转、判据有没有说谎**。

## 跑了什么

两轮，再加两个探针（第一轮三角度，第二轮三角度 + 两探针）。

| 轮 | 角度 | 材料 | 结果 |
| --- | --- | --- | --- |
| 一 | 角度一 / 角度二 / 冷读 | 初稿两篇 | 见 `review-01.md`：两篇总判均「补」，补判后**未重审** |
| 二 | 角度一 | **已补判**的两篇 | 两篇总判均**过**（增量价值 ＋ 何时别用四栏全过） |
| 二 | 角度二 | **已补判**的两篇 | 两篇总判均**补**——前 3 栏全过，**行为示意槽两篇都不过**，无 ground 清单反而变长 |
| 二 | 冷读 | 已补判的两篇 | 复述与边界两篇都成；《边界压缩》挑出 `ask-matt`、`keepRecentTokens`，《迟到者不补播》写「无」 |
| 探针 A | 角度二 | **补判前**的《迟到者不补播》 | 复现已知病灶，并挑出第一轮漏掉的一条 |
| 探针 B | 冷读 | 同上一份文本 | 抓的是「400 张孤儿订单」，与第一轮冷读的「100 帧」**一条都不重合** |

**为什么要探针。** 票面要求「样章里该故意留一两处毛病」——第一轮是自然病灶，没有植入。探针把补判前的文本原样拿给一个 fresh 审读员，补上这一课：**已知毛病，新的冷静读者挑不挑得出来。** 这是这套机制唯一能被证伪的地方——没有真值，至少还有已知答案。

**环境与隔离**：`pi -p`，替换 system prompt（`docs/adversarial-review.md` 那段人格原文），工具只有 `read`，`--no-session --no-skills --no-context-files`，材料放在隔离目录（只有正文＋门槛卡＋`GLOSSARY.md`），审读员互不可见、也读不到 `review-01.md`。第二轮的五个 run 并行，模型 `stepfun-sb/step-5-preview`。原始报告全文见文末。

## 判据逐条填判

### 0. 票面最重要的那条：砍率是不是 0

**两轮五份报告，0 砍。按票面字面，校准失败。**

但它失败的方式是「判据坏」，不是「机制空转」——证据在下面九条：五份报告挑出的真问题几十处，含一处只有角度二抓得到的结构性硬伤，且探针证明这些抓法**可复现**。真实原因是出口表里**「砍」只有一条窄路径**（差异点退化成形容词），可修的缺陷一律走「补」；用「砍」计数，等于要求审读员按唯一的死刑条款判每一个瑕疵。

**决定：判据改成「零发现」，不叫「零砍」。** 见下面第 5 条与落地的 ADR 加注。

### 1. 审读员挑不挑得出已知的毛病？

**挑得出，可复现，而且能挑出第一轮漏掉的。**

- 探针 A（角度二，补判前文本）：复现了第一轮那处结构性硬伤——示意写「第四步做完，第五步要人点头」，视图却写「3 完成 / 1 等待 / 1 待决」，场景又说「第四步卡在需要人点头的地方」，三处口径互斥；`帧` / `状态机` / `花费` 三处无 ground 也各自被点到。
- 同一份报告**新挑出一条第一轮没看见的**：正文用「会话」解释 `view`（「view：会话此刻的只读状态」），而「会话」自己四处出现、一次都没 ground——循环定义。这条比第一轮抓的那几条更硬，说明第一轮不是穷尽的，第二轮不是抄的。
- **冷读那一路不稳**：同一份文本，第一轮冷读抓「100 帧 无出处」，探针 B 抓「400 张孤儿订单」，**互不重合**。冷读是一次抽样，不是一次检验——这个读数写进了规程（见第 10 条）。

### 2. 骨架撑不撑得住？第七槽要不要治？

**撑得住；第七槽要治。**

第二轮角度二对两篇各写了一份逐槽表，**独立地**把两篇的行为示意槽判成不过，理由与第一轮同一词：填字游戏——把组合机制换了个 code block 的排版，没给出一条正文别处没有的轨迹或状态差别。两篇的补法它都指出来了：《边界压缩》该画的是「选段边界随压缩移动、两笔写入落在边界内外两侧的不同命运」；《迟到者不补播》该画的是「同一时刻，事件流下第 95 分钟看到什么 vs 不补播的 `watch` 下看到什么」——开会那 90 分钟在示意里是空白，正好错过了唯一能画「迟到」的地方。

更糟的一处是第二轮**新挖出来**的：《边界压缩》示意的阈值那一支写「阈值到了 → 同时 edit 正在落盘」，可组合机制自己刚说过「上下文小于 keepRecentTokens 时什么都不会压」——示意没画那道闸，右支在它自己的机制下并不必然发生。**示意不自洽的病灶不是一处，是会新增的。**

**决定：不删第七槽**（「示意就是填字」的患者是槽位空着，删槽等于承认这里没有承重内容），而是把判据写进规程。判据两条，见落地的规程改动：
1. 它必须给出**一条正文别处没有的轨迹或状态差别**（时间轴上的位移 / 同一时刻两个做法的可见状态差 / 失败时各自的样子）。纯重排组合机制＝填字，该栏不过。
2. 它必须与**场景、与它自己列出的状态、与组合机制里的闸**自洽。不自洽＝该栏不过，走补。

### 3. 400–900 字够不够？

**够，但计数口径没成文。** 第一轮报的是正文 827 / 816 字；探针 A 实测《迟到者不补播》**含 front matter 与代码块**约千字、压上限、微超一成。两轮都不认为「讲不清」，但同一个稿子在两份报告里有两种字数——**正式写稿前得有一条计数口径**（含不含门槛卡、含不含示意块）。这条转给第一张写作票。

### 4. 就地注解会不会打断阅读节奏？

第一轮的结论不变：断点不在括号的数量，在**括号的质量**——是「谁有资格被注」漏了网。第二轮把这条从定性升级成定量问题：

- 同一份文本（补判前的《迟到者不补播》），第一轮角度二列 3 条无 ground，探针 A 列 4 条：重合 3 条（帧 / 状态机 / 花费）、新增 1 条。**ground 这一栏本身是可复现的**；不稳的是清单的**边界在哪**。
- 但第二轮对**已补判**的稿子，无 ground 清单反而更长（《边界压缩》5 条，《迟到者不补播》4 条）：`head 标记` / 五个选项里的 `clear`、`handoff`、`subagent` / 裸「阈值」/ `overflow` / `ask-matt` / `进度流、会话流、事件流` / `task` / `检查点`。补掉两条注之后数字从 3＋3 涨到 5＋4 —— 因为**每一次判都不按同一份尺子**。

这不是审读员在找茬——是 **ground 的判据没有成文标准**，于是清单长度成了审读员口味的函数。这在取严档下会变成事故（见第 7 条）。**决定：把 ground 判据写进规程**：一句「它是哪一层的东西」或一句边界算 ground；通用技术词（agent、prompt、token、context）与字面名（枚举值、方法名）免注；**用被 `GLOSSARY.md` 标为 Avoid 的词去解释另一个词不算 ground**（第二轮抓到的实例：`entry` 的括注用「记录／条目」解释 Entry，而那正是 Entry 词条的 Avoid 词——这条转 #6）。

### 5. 五道门槛在具体文稿上判得动吗？

**判得动，且第一轮的补判生效。** 第二轮角度一对两篇的四栏（单边做法 / 组合做法 / 差异点 / 何时别用）**全部判过**，两篇总判都是过——第一轮判「补」的「何时别用」栏（判据从「有没有在飞的写入」改成「丢掉的写入有没有人在等」）这次独立通过。前 3 关由第二轮角度二判，也全过。

所以：**门槛五关、骨架七槽、冷读一轴，三者各自能判，且互不代替**——第二轮最干净的证据就是两篇「门槛全过、骨架不过」。

### 6. 零砍批：判据改掉（本条是本次校准的主要产出）

ADR-0005 第四条把它定义成「一整批一条没砍」。校准实测：**健康批会误报**。两轮两篇、20 处真发现、含一处结构性硬伤，砍数是 0——因为出口表把「砍」留给了唯一一条窄路径。

**改判据**：信号名改为**零发现批**，判的是「**一整批没有任何一栏被判不过或无法判定，且冷读三行都给不出问题**」。连续 2 批触发停批质检（动作不变），并保留判词引用率这一项检查。

名字一起换：继续叫「零砍」，读的人会以为它数的是砍；而这个仓库自己就写着「名字撒谎比没有名字更坏」。

### 7. 取严档会不会把好稿砍掉？

**没被考到——两轮零分裂，取严一次都没行权。** 但校准顺手把它的风险摆出来了：分裂最可能发生在哪一栏？**ground 栏**——因为它是唯一没有成文尺子的一栏（同一份文本上两份报告 3 条 vs 4 条，冷读那一路干脆 0 重合）。分裂一旦落在这里，取严＝按**最严那位审读员的口味**砍，而那个口味没有被任何成文标准约束。**所以取严的前提不是审读员够狠，是判据够成文**——这是第 4 条那条 ground 判据真正的理由。取严档本身仍待考，写进 ADR-0005 的账单。

### 8. 轴内重复检测说得出话吗？

**说得出，但没料可说。** 「和同轴已定的哪条是同一件事」这一栏，两轮八个审读员全部空转：第一轮写「无可比条目」，第二轮的角度一继续写「无可比条目」——同轴一条都没毕业。规程里没写这种情况怎么办，于是每个审读员都为它写一句废话。**决定：规程补一句「同轴无已毕业条时跳过该栏，不写空话」**；等第一张选料票发出号段之后，这一栏才有第一次真实输入。

### 9. 书级冷读的举证纪律落不落得了地？

**落不了——无从校准。** 单位是整本，而书稿一行都没有；两篇 proto 是证据、不进书。这条留在账单里：**第一张写作批 + 书级冷读是第二次校准点**（好在 ADR-0005 已经把「书级冷读报告处理完才能终读」钉死，机制不至于漏掉这一步）。

### 10. 冷读的隔离是假的（方法缺陷，本票就地修）

规程写「只喂正文」，可**门槛卡就挂在同一个文件的 front matter 里**——物理上喂不掉。第二轮冷读报告里直接引用了「文头门槛卡」，实锤。**决定：规程写明冷读前剥掉 front matter**（打稿给冷读时删掉 `---` 那一段，或明令不读）。这是 #5 / #8 定的形态（门槛卡住 front matter）与这里的隔离要求第一次打架——本票只在规程上打补丁，不改那里的物理形态。

## 一、《边界压缩》（轴：上下文经济学）

| 栏名 | 判词（引正文原句） | 判定 |
|---|---|---|
| 单边做法 | 「单边读者的答案是 ask-matt 那条纪律：逼近 *smart zone* 就 *compaction*……它把压缩当清理房间：快满了就扫一下」——真做法，与门槛卡一致，且术语宪法里 *smart zone* 条目本身就写着「逼近了就 compact」 | 过 |
| 组合做法 | 「于是队列反过来排——**边界压缩是策略，阈值压缩降级成兜底**（后台阈值压缩是保险丝，不是决定）」；「边界是『没有在飞的写入』的时刻，阈值是『资源快没了』的时刻」 | 过 |

| 何时别用 | 「探索阶段：写入不承重——丢了随手能重写，也没有下游在等它。这时随手压的损失近乎零……判据是『丢掉的写入有没有人在等』，不是『有没有在飞的写入』——后者在探索阶段恰好最多」 | 过 |

总判：过

## 二、《迟到者不补播》（轴：人类检查点与注意力）

| 栏名 | 判词（引正文原句） | 判定 |
|---|---|---|
| 单边做法 | 「单边做法是 *push right*（把人被问到的时机尽量往后推，只问一次，且材料齐备）」——真做法。卡中「人的界面是一条进度流」八字正文未现，对应句是「常见的会话流、事件流给不了这份保证——重连的客户端要么丢帧，要么给你补播一大段，而补播回来的已经是过去的事实」，实质在场 | 过 |

- **天真做法为什么不够**｜齐：「它是好纪律，但它要一份保证才成立：**你晚到的时候，当前状态就是全部**……人一旦要自己从流里重建「现在在哪」，检查点就从一次决定退化成一次考古。」
- **组合机制**｜齐：「运行时侧有两条事实正好是那份保证。一是 *commit*……二是 *watch*……」
- **行为示意**｜槽位在（有标题有内容），**内容不过**，单独判于下。
- **何时不适用**｜齐：「要**证明**发生过什么的时候。视图不是账本：它没有历史……事实必须写成不可变的 *entry*」
- **回扣 leading word**｜齐：见上引回扣段。

另记一笔：骨架构词规定 400–900 字；本篇含标点与代码块实测约千字，压在上限、微超一成。不单独判死，但与下一条一起补。

### 行为示意槽单独判：不过

**是轨迹还是重排？——是重排，填字。** 它列的三态「3 完成 / 1 等待 / 1 待决」就是组合机制里「完成、等待、待决都在视图里」换了行；那句「要删这 400 张孤儿订单吗？」是从场景原句「一句『要删掉这 400 张孤儿订单吗』」整段搬来的；「没有回放，也没有『我漏看了什么』这回事」是场景「没有回放，没有『这三步是怎么走到这里的』」加机制「什么都不重放」的改写。真正新的只有分钟刻度和「状态落盘」——那是排版，不是轨迹。

**自洽吗？——三处口径不一，含一处硬伤：**
1. 跟自己列的视图不自洽：「第 90 分钟  你在开会；第四步做完，第五步要人点头」——第四步做完就该是 4 完成，可视图写「3 完成 / 1 等待 / 1 待决」。
2. 跟场景不自洽：场景说「第四步卡在需要人点头的地方」，示意说「第五步要人点头」；而视图的 3 完成 / 1 等待恰好对应场景的第四步卡住——即示意的时间线行同时背叛了自己的视图和场景。
3. 次级漂移：场景说「跑了两小时」＋「前 90 分钟在开会」，回来应是第 120 分钟左右，示意第 95 分钟就打开了。

补法二选一：把「第四步做完，第五步要人点头」改成与场景、与视图一致的口径（至少消掉硬伤）；或重写成一条正文别处没有的轨迹——比如同一时刻补播派与订阅派各走到哪、那 100 帧缓冲实际喂给的是谁——才配得上这个槽。

## 三、没有 ground 的术语／概念

**硬缺口**

1. **会话**（及派生「会话流」「跨会话」）。正文用了四处，没有一处教它：「*watch*（订阅**会话**的变更流）对迟到的客户端**不补播**」「『当前视图』（view：**会话**此刻的只读状态）」「常见的**会话流**、事件流给不了这份保证」「**跨会话**也不汇总花费」。读者从哪一句能学到它：**没有**。最接近的是 view 的括注「会话此刻的只读状态」，可它本身是拿「会话」解释 view，循环定义。冷读者只能从「一个跑了两小时的活儿／派活」猜它是跑活的容器——猜对也不算 ground。术语宪法里 Session 是承重内核对象，本篇欠一句「它是哪一层的东西」。

**从严列入的半缺口**

2. **状态机**：「而检查点的内容由任务（task）自己的**状态机**给齐了——完成、等待、待决都在视图里」。破折号后的枚举把状态名给了读者，算半救；但「状态机」本身（谁驱动转换、每步存 checkpoint）无一句交代。
3. **帧**：「最多缓冲 100 **帧**未交付的更新——而那个缓冲是给慢消费者的，不是给人的历史」。句子说明了缓冲用途，「帧」作为变更流单位仅靠「未交付的更新」反推；连同天真段「要么丢帧」，读者始终没被正式告知帧是什么。
4. **花费**：「跨会话也不汇总**花费**」。花的是什么（token、机时、钱）正文无一字，仅靠同段后面的「计费」反推是钱。

**已扫过并放行的**：push right、commit、view、watch、entry、检查点、补播、待决问题、进度流均在首次出现处有括注或定义；「任务（task）」的括注偏薄（「自己的状态机」），但紧随的状态枚举兜住了，不单列。

**附注（转交术语视角）**：entry 的括注「（记录：一条不可改写的条目，历史只能追加）」拿「记录」「条目」当解释词——正是术语宪法给 Entry 开的 Avoid 词。ground 有了，译名合规存疑。

总判：补

### 探针 B · 冷读（同一份补判前文本）

复述：迟到者不补播——人的检查点就是「当前视图＋一句待决问题」，因为运行时不补播，当前状态即全部事实。

边界：说得出台——要证明「当时发生过什么」时（事故复盘、计费、合规）别拿界面当账本，事实必须写成不可变 entry；此时「把一切记下来给人看」才是唯一对的。

裸术语：「要删掉这 400 张孤儿订单吗」——「孤儿订单」指什么，正文始终没交代。
